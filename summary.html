4. s → v → a

s→ดิฟ v→ดิฟ a
  • ดิฟ = ไปขวา · อินทิเกรต = ย้อนซ้าย
  • ให้ a มา: อินทิเกรตครั้งที่ 1 ได้ v ครั้งที่ 2 ได้ s
  • หา C ให้จบทีละชั้น v(0) ใช้กับชั้น v · s(0) ใช้กับชั้น s
  • หยุดนิ่ง = v = 0 · ความเร็วสูงสุด = a = 0

5. สูงสุด / ต่ำสุด

  • สัมพัทธ์: f′(c)=0 แล้วดู f″(c) — ลบ = สูงสุด · บวก = ต่ำสุด
  • สัมบูรณ์บน [a,b]: แทนค่าวิกฤต และปลายช่วงทั้งสอง แล้วเทียบตัวเลข
  • เห็นวงเล็บเหลี่ยม [ ] เมื่อไหร่ = อย่าลืมปลายช่วง
  • ข้อพิสูจน์: คำตอบถูกต้องมี สองเงื่อนไข เสมอ (f′=0 และ f″<0) ไม่ใช่อันเดียว

6. พื้นที่ปิดล้อม

  • เหนือแกน: A = ∫f dx · ใต้แกน: A = -∫f dx
  • เช็คจุดตัดแกน x ก่อนเสมอ (แก้ f(x)=0)
  • ถ้าจุดตัดอยู่ในช่วง → แบ่งสองก้อน แล้วบวกขนาดของทั้งสอง
  • สองเส้นโค้ง: A = ∫(บน - ล่าง) dx
  • พื้นที่ติดลบไม่มีในโลก เห็นตัวเลือกติดลบ ตัดทิ้ง

7. เทคนิคปรนัย — 3:20 ต่อข้อ

  • 5 นาทีแรก กวาดอ่านทั้ง 15 ข้อ ทำข้อง่ายก่อน

  • โจทย์ให้จุด → แทนจุดลงตัวเลือก อย่าเสียเวลาหา C
