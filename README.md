# ติวแคลคูลัส — อินทิเกรต + การดิฟแบบประยุกต์

ชีทติวสอบภาษาไทย HTML ล้วน ไม่มี dependency ภายนอก เปิดได้ทุกเบราว์เซอร์ทั้งคอมและมือถือ

| ไฟล์ | คืออะไร |
|---|---|
| `index.html` | หน้ารวม ลิงก์ไปทุกไฟล์ |
| `cram.html` | ชีทติวเข้ม 8 บท พร้อมตัวอย่างเฉลยทีละขั้น จับเวลา และ checkbox ติดตามความคืบหน้า |
| `mock.html` | ชุด A — ข้อสอบเสมือน 15 ข้อ นับถอยหลัง 50 นาที (ตรงสเปกข้อสอบจริง) |
| `mock2.html` | ชุด B — 20 ข้อ นับถอยหลัง 65 นาที กวาดครบทุกหัวข้อ ระดับเท่าข้อสอบจริง |
| `mock3.html` | ชุด C — 20 ข้อ นับถอยหลัง 65 นาที ยากกว่าหนึ่งขั้น ทุกข้อมีกับดัก |
| `summary.html` | สรุปหน้าเดียว สำหรับอ่านในมือถือก่อนเข้าห้องสอบ |

ทั้งสามชุดเป็นปรนัย 4 ตัวเลือก เลือกแล้วกดส่งครั้งเดียว ไม่เฉลยระหว่างทำ
มีตัวนับข้อที่เว้นว่าง และเฉลยพร้อมวิธีทำเปิดอัตโนมัติหลังส่ง

**ลำดับที่ควรทำ:** `cram.html` → `mock.html` → `mock2.html` → `mock3.html` → `summary.html`

## เนื้อหา

1. รูทและเลขชี้กำลังเศษส่วน
2. ปฏิยานุพันธ์ และทฤษฎีบทหลักมูลของแคลคูลัส
3. อินทิเกรตเศษส่วน
4. ระยะทาง ความเร็ว ความเร่ง
5. ค่าสูงสุด/ต่ำสุด สัมพัทธ์ และ สัมบูรณ์
6. พื้นที่ปิดล้อมด้วยเส้นโค้ง
7. เทคนิคทำข้อสอบปรนัย

ทุกหน้ารองรับธีมสว่าง/มืดตามเครื่อง และสั่งพิมพ์ได้
